### 🔐 Cipher --- File Encryption & Decryption

> Privacy-focused application for securely encrypting and decrypting
> files.

-   AES-128 / AES-192 / AES-256 workflows
-   Encryption and decryption for multiple file formats
-   Secure key generation
-   Downloadable encrypted output
-   Restore the original file using the correct key
-   React + TypeScript based interface

**Live:** [c-i-p-h-e-r.netlify.app](https://c-i-p-h-e-r.netlify.app/)

------------------------------------------------------------------------

### 🧠 Dyslexic Friendly Buddy

> An accessibility-focused learning platform designed to make digital
> reading and studying easier for users with dyslexia.

**Core modules**

-   OCR --- image and document to text
-   Text-to-Speech with read-along support
-   Speech-to-Text note taking
-   AI-assisted text simplification
-   Contextual Q&A
-   Smart notes
-   Dyslexia-friendly fonts and themes
-   Adjustable reading experience
-   Cloud-backed data architecture

**Research:** *Dyslexic Friendly Buddy: An Integrated OCR--TTS--STT and
Read-Along System for Accessible Reading Support*
